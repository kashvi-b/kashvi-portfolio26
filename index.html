MedGraph: agentic clinical document intelligence

A LangGraph agent that answers questions over a public healthcare-policy and drug-label corpus, and refuses when the corpus cannot support an answer.

  • Python
  • LangGraph
  • LangChain
  • Pydantic v2
  • FastAPI
  • PostgreSQL
  • pgvector
  • Docker
  • Seven-stage state machine: scrub, classify, extract, retrieve, synthesize, verify, refuse.
  • Typed models with Pydantic v2 and FastAPI endpoints.
  • Vector retrieval on PostgreSQL with pgvector, containerized with Docker.
  1. Corpus
  2. Input processing
  3. Classify and extract
  4. Retrieve
  5. Synthesize
  6. Verify
  7. Answer or refuse

Conceptual workflow. Not every request follows an identical path. MedGraph is a document question-answering project, not a clinically validated diagnostic system.

View code
View details

Problem

Answers over healthcare policy and drug labels must be grounded. A plausible but unsupported answer is worse than no answer.

Approach

The agent scrubs input, classifies the question, extracts key fields, retrieves passages from pgvector, drafts an answer, then verifies it against the retrieved evidence. If support is missing, it takes the refusal path.

Technical choices

LangGraph makes each stage explicit and testable. Pydantic v2 keeps data between stages typed. FastAPI exposes the agent, and Docker packages it with its database.

Limitations

Built on a public corpus for demonstration. No clinical validation has been performed.

View codeLive demo
View details

Problem

Understand where and why shipments are delayed, and which suppliers carry the most risk.

Approach

Designed the star schema, wrote 15 SQL queries using CTEs and LAG, NTILE and RANK for delivery, supplier and inventory KPIs, then ran validation, EDA and root-cause analysis in Python.

Models

A Gradient Boosting classifier predicts delay (AUC 0.81) and a severity model estimates delay length (MAE about 11 days). Both feed shipment risk scores and supplier scorecards.

Limitations

All data is synthetic, so the financial figures illustrate a method, not measured outcomes.
